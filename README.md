# coastal-dynamics

## Description
The coastal-dynamics package was developed at Delft University of Technology by the Coastal Dynamics course as an educational tool to facilitate an online and open source ecuational suite. 

## Installation
To install the coastal-dynamics package from PyPI, run 'pip install coastal_dynanmics'.
